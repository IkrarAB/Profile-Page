# Personal Profile Website — Ikrar Anugrah Bastary

A clean, responsive personal profile website built with HTML, Tailwind CSS, and vanilla JavaScript.

## Features
- Light and dark mode toggle with saved preference
- Interactive tech stack filter by category (Backend, Frontend, Database, Tools & DevOps)
- Project highlight cards with detail modals
- One-click email copy with toast notification

## Quick Push to GitHub
1. Create a new repository on [GitHub](https://github.com/new) (for example, `profile-website` or `IkrarAB.github.io`).
2. Unzip this folder and run:
   ```bash
   git init
   git add .
   git commit -m "Add personal profile website"
   git branch -M main
   git remote add origin https://github.com/IkrarAB/profile-website.git
   git push -u origin main
   ```
3. (Optional) Enable **Settings → Pages** and select the `main` branch (`/root`) to publish the site live on GitHub Pages.
